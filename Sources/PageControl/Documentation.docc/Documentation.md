# ``PageControl``

`PageControl` is a SwiftUI wrapper around `UIPageControl`.

## Overview

Most of its APIs have been carried over via [`Environment`](https://developer.apple.com/documentation/swiftui/environment)/[`EnvironmentValues`](https://developer.apple.com/documentation/swiftui/environmentvalues).

Based on [Apple's UIViewRepresentable tutorial](https://developer.apple.com/tutorials/swiftui/interfacing-with-uikit).
