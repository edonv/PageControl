[![](https://img.shields.io/endpoint?url=https%3A%2F%2Fswiftpackageindex.com%2Fapi%2Fpackages%2Fedonv%2FPageControl%2Fbadge%3Ftype%3Dswift-versions)](https://swiftpackageindex.com/edonv/PageControl)
[![](https://img.shields.io/endpoint?url=https%3A%2F%2Fswiftpackageindex.com%2Fapi%2Fpackages%2Fedonv%2FPageControl%2Fbadge%3Ftype%3Dplatforms)](https://swiftpackageindex.com/edonv/PageControl)

`PageControl` is a SwiftUI wrapper around [`UIPageControl`](https://developer.apple.com/documentation/uikit/uipagecontrol). Most of its APIs have been carried over via `Environment`/`EnvironmentValues`.

Based on [Apple's UIViewRepresentable tutorial](https://developer.apple.com/tutorials/swiftui/interfacing-with-uikit).
